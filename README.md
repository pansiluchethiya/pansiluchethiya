## About

I'm **Pansilu** — a student developer whose hobby is building random, fun projects. That's literally my
GitHub bio, and it's the most accurate thing I've written about myself.

Most repos start as a "what if" I can't stop thinking about: a self-hosted streaming backend, a
browser-first chat app, a diagnostic AI built for an exhibition, a Python crawler that ended up on
PyPI. I write mostly in **TypeScript** and **Python**, and the best part is the moment a weekend
prototype turns into something somebody else can actually open and use.

Right now that mostly means shipping small things end to end — API, UI, database, deployment — and
keeping the parts that are actually fun.
